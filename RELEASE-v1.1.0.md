# Release v1.1.0 – Schnupper

Die Präsentation hat eine neue Folie, die Demos bleiben unverändert.

## Präsentation

- **Neue Folie „Ein Agent bei der Arbeit“:** In zehn Klicks liest ein Agent das Referat von der Copy-&-Paste-Folie und schreibt Absatz 3 neu. Dabei ist zu sehen, wie Modell, Harness und Werkzeuge zusammenspielen und dass das Harness in jeder Runde den ganzen Verlauf mitschickt.
- **Neue Reihenfolge:** Der Abschnitt „Vom Chatbot zum KI-Agenten“ geht jetzt vom Beispiel zum Prinzip. Erst kommt die neue Folie, dann „Aufbau eines KI-Agenten“, zuletzt der Kreislauf. Die Sprechernotizen sind angepasst.
