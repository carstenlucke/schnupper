# Release v1.1.1 – Schnupper

Dieses Release überarbeitet die Präsentation, die Demos bleiben unverändert.

## Präsentation

- **Kreislauf vor dem Durchlauf:** „Wie arbeitet ein KI-Agent?“ kommt jetzt vor „Ein Agent bei der Arbeit“. So ist schon klar, was eine Runde ist, wenn die Schleife im Harness die Runden zählt.
- **Merksatz zum Harness:** Auf „Aufbau eines KI-Agenten“ erscheint per Klick „Das Harness macht den Unterschied.“
- **Notizen für Lesende:** Die Notizen unter den Folien richten sich jetzt an alle, die die Präsentation später allein durchgehen. Sie erklären die Folie in ganzen Sätzen und gehen über das Gesagte hinaus. Regieanweisungen und Bedienhinweise zu den Demos sind entfallen.
