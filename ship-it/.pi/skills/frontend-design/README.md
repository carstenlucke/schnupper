# frontend-design

Leitfaden für eigenständiges, nicht schablonenhaftes Webdesign: Designplan aus
Farben, Schrift und Layout, Abgleich mit den typischen Mustern generierter
Seiten, dann Umsetzung und Selbstkritik.

## Herkunft

Unveränderte Kopie des Skills `frontend-design` aus dem Plugin-Verzeichnis
[claude-plugins-official](https://github.com/anthropics/claude-plugins-official)
von Anthropic.
